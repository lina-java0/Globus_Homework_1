При копировании без буферизации программа читает и записывает файл по одному байту за раз.
Для файла размером 100 МБ это означает более 100 миллионов операций чтения
и примерно столько же операций записи.

Каждая операция имеет накладные расходы:
вызовы методов, переходы между Java и нативным кодом, взаимодействие с операционной системой.

При использовании буферизации данные обрабатываются блоками по 8192 байта (8 КБ).
Вместо обработки каждого байта отдельно программа выполняет значительно меньше операций чтения и записи.

Таким образом, буферизация сокращает количество операций и накладные расходы на их выполнение,
благодаря чему копирование происходит значительно быстрее.
